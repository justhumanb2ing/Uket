Uket is a lightweight ticketing platform designed for small-to-medium events such as university festivals and club performances.
It enables organizers to manage ticket sales efficiently and allows attendees to enter events seamlessly without on-site queues.

### Overview

Traditional campus events often rely on manual lists, bank transfers, and on-site verification, which cause operational friction and long entry lines. Uket solves this by providing a streamlined pre-ticketing and admission workflow optimized for real-world event environments.

The platform was validated during a live university performance (\~100 attendees), handling the full flow from ticket purchase to QR-based entry without operational issues.

### Key Features

- Time-slot based ticketing for crowd distribution
- QR-based admission system
- Automated notification delivery (KakaoTalk AlimTalk notifications)
- Lightweight UX optimized for real event usage
